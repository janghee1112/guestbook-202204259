# 로그인 없이 글마다 비밀번호를 두고, scrypt 해시로만 저장한다

요구사항이 "회원가입/로그인 없이 글 쓸 때 입력한 비밀번호로 본인 글만 수정·삭제"이므로 계정·세션 없이 글마다 비밀번호를 받는다. 원문은 저장하지 않고 글마다 무작위 salt + Node 내장 scrypt 해시만 저장하며(외부 bcrypt 패키지 없이), 목록·API 응답에는 해시를 절대 포함하지 않는다. 확인은 서버에서만 하고, 수정·삭제 SQL은 "확인에 쓴 해시와 같은 행"만 바꾸도록 조건을 걸어 확인과 변경 사이에 다른 요청이 끼어들어도 안전하게 한다.
