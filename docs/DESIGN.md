# 디자인·모션 브리프

## 디자인 — 흰 배경 애플 스타일
- 느낌: apple.com 제품 페이지. 흰 배경, 넓은 여백, 크고 단단한 타이포, 요소는 적게, 색은 절제.
- 색: 배경 #FFFFFF / 보조 배경 #F5F5F7 / 본문 #1D1D1F / 보조 글자 #6E6E73 / 구분선 #D2D2D7 / 강조 #0071E3 한 가지 / 오류 #E30000.
- 폰트: Pretendard(한글·영문·숫자). 제목 700, 자간 -0.02em~-0.04em. 본문 17px 근처.
- 히어로 제목: clamp 로 화면 폭에 맞춰 커짐(데스크톱 80~128px).
- 레이아웃: 최대 폭 1080px 중앙, 섹션 여백 120px 이상, 카드 모서리 22~28px, 그림자 거의 없음.
- 상단 내비: 얇은 반투명 흰 바(backdrop-blur), 스크롤 시 살짝 진해짐. 개발자 이름·학번 표시.
- 버튼: 알약 모양. 강조 채움 1종 + 테두리형 1종. 호버·누름이 부드럽게 반응.
- 입력창: 큼직하게, 포커스 시 강조 색 링이 부드럽게.
- 빈 상태·에러도 같은 톤. 모바일 375px에서 가로 스크롤 없음.
- 레퍼런스(분위기만): notion-scroll-film(스크롤에 따른 장면 전환·이징), realevate.agency(큰 타이포·카드가 화면을 채우며 들어가는 느낌), usavionix.com(절제된 순차 등장).

## 모션 — "살짝 빨려 들어가는" 느낌
라이브러리: gsap(+ScrollTrigger), lenis. 클라이언트 컴포넌트에서만, 언마운트 시 정리.
1. 부드러운 스크롤: Lenis(lerp 0.1 근처). 터치 기기는 기본 스크롤.
2. 스크롤 등장: 요소가 화면에 들어올 때 아래에서 32px 떠오르며 투명→선명(blur 8px→0), 0.06~0.1초 간격 순차. 한 번만.
3. 히어로 scrub: 스크롤하면 큰 제목이 scale 1→0.9, 흐려지며 다음 섹션이 올라옴.
4. 빨려 들어가는 전환(핵심): 글 카드를 누르면 카드가 제자리에서 커지며 화면 중앙의 상세 패널이 되고, 뒤 배경은 흐려지며 물러난다. 닫으면 원래 카드 위치로 줄어들며 돌아간다. 0.5~0.7초, power3.inOut 계열.
5. 작은 상호작용: 호버 시 translateY -2px, 누르면 scale 0.97, 새 글은 목록 맨 위에 부드럽게 끼어듦, 비밀번호 틀리면 입력창이 좌우로 짧게 흔들림.
6. prefers-reduced-motion 이면 모션을 즉시 전환/짧은 페이드로 대체. transform/opacity 위주. 모션이 없어도 기능 100% 동작.
7. 금지: 과한 파티클/3D, 큰 커서 효과, 1초 넘는 로딩 애니메이션, 스크롤 강제 가로채기.
